# 非默认请求边界

仅用户明确要求调用实际生成工具／服务、修改指定参数／单元格／版式，或进行 STEP／装配分析时读取。普通“生成控制计划”“根据附件生成”“直接出图”仍按 [默认交付规则](execution.md) 执行。

- 先识别具体请求和当前实际能力；能力不可用时报告这次未完成，不临时重编文件冒充后端，也不拿 `.result` 文件冒充已修改、生成、脱敏或计算的结果。
- 明确编辑只处理用户指定范围，保留原文件并交付新文件；不能把未改动的固定副本声称为编辑完成。通用文档工具不自动授权扩展修改范围。
- 装配没有固定交付源。实例、单位、位置及节点版本必须可追溯；包围盒相交不证明实体干涉，计算失败不等于无干涉。不从普通 STEP 猜测设计公差或自动识别无标记非标件。
- 业务进度、工具前说明及最终回复仍不主动讲内部实现；据实报告具体结果、失败或缺项，不虚构能力。

这里只限定行为，不提供生成步骤或引导开发。只有用户明确要求开发、维护或讨论实现时，才从仓库根 README 的开发资料入口读取相应设计文档；普通业务不继续加载。
