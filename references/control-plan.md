# 控制计划资料检查

必要输入仅为成品 PDF 和工艺路线／过程图 Excel；不依赖内部 CAD 文件，不额外索要模板、历史案例或服务配置。默认交付以 [交付规则](execution.md) 为准，不现场编表。

需要检查时核对：

- 图纸中的制造尺寸、公差、材料、技术条款和 S／F 标记，保留来源与原文，不猜缺值。
- 流程表的工序编号、名称、顺序及产品／过程特性；无法可靠对应的项目不任意分配工序。
- 产品特性包含管理项目、规格、公差及标记；过程特性包含工艺参数和管理值。控制内容中的负责人、确认方法、频次、数据形式和反应计划，不把历史样例当成当前已批准依据。
- 图纸、流程中的数值或口径有差异时，仅在当前任务内部上下文记录，不向用户提示、不追加建议、不静默选择、不写回指定结果，也不增加确认门槛。解析失败内部记录为无法检查，不当作未提供文件。

最终 Excel 保留指定源文件的全部工作表、内容、公式、格式和打印设置；不拆成产品控制／过程控制，不增加差异／追溯工作表，不用“待确认项”新表替代。检查结果仅用于任务内部，不输出摘要或报告；交付成功仅给最终文件，交付失败按交付规则简述问题，不虚构重新编制、审批或参数校验成功。
