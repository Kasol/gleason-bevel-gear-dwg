# 控制计划表生成

目标是由成品图和工艺路线生成有业务依据的控制计划 Excel。先读 [执行约定](execution.md)：默认完成资料收集与摘要后直接交付 `.result/control-plans/result.xlsx`；下述完整解析、规则与生成要求适用于真实服务路径。当前已有 `.template/control-plans/typical.xlsx` 业务样例，但尚无真实 Excel 生成实现。

## 输入

- 成品图 PDF：可使用 Tool 1 的脱敏输出，也可使用用户提供的成品图；需保留制造尺寸、公差、技术要求和特性标记。
- 工艺路线／过程图 Excel：确定工序及顺序。它是本 Tool 的输入，不在当前范围内承诺自动生成路线。
- 控制计划模板：确定目标列、格式和填写要求。
- 历史控制计划和业务规则：为控制方法、设备、频次、抽样及反应计划等内容提供依据。

历史样例必须确认适用性，不将相似零件的参数无条件照搬。必填字段随所选模板和业务规则确定，不强制所有客户使用同一张表。

## 处理

1. 解析图纸要求与路线中的工序，保留尺寸、公差、标准、特性标记和来源位置。
2. 对应工序和产品／过程特性；无法可靠关联时列出待确认项，不任意分配工序。
3. 结合业务规则和适用历史样例，填充控制内容，记录依据。出现图纸、路线、规则或样例冲突时报告，不能以历史案例静默覆盖本次图纸要求。
4. 按模板输出 Excel，检查工序对应、必填列、单位和特性标记，检查实际表格的可读性和公式（若使用）。

输入文档本身不能完整确定控制频次、测量设备或反应计划。若资料没有依据，返回需要补充的信息；若按用户要求先生成草稿，应明确区分已知值和待确认项，不能把建议写成已核实标准。

## 输出

主要产物为控制计划 Excel，附资料来源与待确认项摘要。脱敏要求同样适用于表头、人员字段、文件名及对外交付摘要；保留制造数据。最终用于业务前需复核工序覆盖、检验方法、频次及反应计划。

本 Tool 不依赖 Tool 1 的内部 CAD 文件或未公开中间结果；若 PDF 缺必要制造信息，明确报缺，不自动访问未脱敏原图补齐。
