# 技术要求与特性标记

技术要求来自用户显式输入或草图提取，并按所选模板及业务规则整合。旧技能的固定五条仅作为锥齿轮业务示例，不再是所有 Tool 必须逐字输出的通用条款。

下述条款识别和内容校验可用于两条路径。默认流程发现差异或识别失败后记录并继续交付，补充资料仅按 [执行约定](execution.md)；真实生成再按适用规则处理完整性及冲突。两条路径都不能凭空填写硬度、公差等数值。

## 条款处理

- 保留已确认的技术条款原文、顺序、标准号及版本，不擅自修改工艺含义。
- 根据模板映射整理字段；识别不足或字段留白时保留未确认，不能从历史案例或“常规值”猜测。默认流程不逐个追问已提交资料中的工程细节。
- 用户说“按常规”时，仍须有可定位的公司规则或明确值；没有依据则记录，真实生成需要补充时再请求。
- 图纸、用户输入或业务规则有冲突时保留来源并报出，不静默选用历史示例。
- 未注线性尺寸公差与未注形位公差分别记录，不能互相替代。倒角也应保留线性尺寸与角度含义，不能只因旧示例写了“°”就作为统一格式。

## 锥齿轮示例字段

| 类别 | 可能包含的字段 | 表达要求 |
|---|---|---|
| 热处理 | 处理方式、有效硬化层深度、表面硬度、心部硬度 | 深度带单位，硬度带标尺，单值／范围按原要求保留 |
| 表面质量 | 烧伤、裂纹等缺陷限制 | 保留适用对象及原文 |
| 边缘处理 | 未注倒角、未注圆角 | 保留 C／R 等符号、尺寸及必要角度 |
| 公差 | 线性尺寸、形位等不同类别的未注公差 | 各自保留标准、等级与适用范围 |
| 特性说明 | S 为关键特性、F 为重要特性 | 由模板和业务规则确定标注位置 |

例如“渗碳淬火，渗层深度 0.8–1.2 mm，表面硬度 HRC58–62，心部硬度 HRC30–45 [S]”仅为表达示例，数值不能用作缺省输入。

## S 与 F

`[S]` 表示产品关键特性，`[F]` 表示产品重要特性。按输入数据与模板规则绑定具体尺寸、参数或条款，不限定 F 只能属于精度等级；业务示例中的内孔和安装距也有 F 标记。

保留标记与特性之间的语义对应关系，不把标记混入数值或标准号。参数化修改和重新排布后，标记仍应指向原本的特性；其字形及展示样式遵循模板。新特性标记需要业务依据，不自行添加。

脱敏只去除指定身份信息，制造要求及特性标记保留，以便控制计划 Tool 继续使用。条款保持确认的原始语言，说明文字跟随用户语言；不强制任何客户的全部条款始终使用固定中文原文。
