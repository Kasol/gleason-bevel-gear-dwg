# 任务文件管理

本规则适用于文件交付、资料读取和服务调用。允许为兼容宿主临时编写 Python 等脚本，但任务结束时只保留用户要求的最终交付物，清理此次操作创建的临时文件。

## 创建与记录

- 为本次任务选用新的唯一标识，不复用旧任务的临时目录或交付目录。优先采用宿主可交付的输出位置；没有约定时，使用当前可写工作区的 `outputs/<任务标识>/`。不要要求已安装技能目录可写。
- 源文件 `.result/` 和 `.template/` 只读使用。成品 PDF 复制为本次目录中的 `二维成品图.pdf`，控制计划复制为 `控制计划.xlsx`。复制目标必须不存在；若目录或文件重名，换用新的任务标识，不覆盖。服务生成的最终文件放到同样独立的交付位置。
- 临时脚本、提取文字、JSON／CSV、转换后的 DXF／PDF、渲染图片、日志和缓存集中在本次新建的临时目录，例如工作区 `.tmp/<任务标识>/`。生成中间文件时让工具使用这个目录，避免写入用户资料目录或技能目录。
- 创建前确认目标不存在；每次创建时在当前任务上下文记录文件的实际路径及用途（临时或最终），目录也记录。无需额外生成清单文件。可控制的子进程缓存也写入本次临时目录，或关闭不必要的缓存。

## 交付与清理

1. 确认最终文件是本次新建、存在且可读取。直接复制时核对内容一致，不为交付额外生成说明文件、备用版本或压缩包。
2. 在完成、失败或取消的收尾阶段，按创建记录逐项删除本次临时脚本、转换件、预览、日志、缓存和失败复制的半成品；最终交付文件保留。
3. 删除前解析绝对路径，确认对象属于本次记录且在本次临时目录或明确记录的新建位置内。不可因文件名相似、时间较新或扩展名为 `.py` 就删除。
4. 仅删除已记录文件，最后删除本次创建且已空的目录。若目录出现未记录内容，不递归清空；先确认归属，无法确认则保留并说明。工具关闭后再清理其文件，不删除其他任务的进程或文件。
5. 复查本次记录：临时文件已清理、最终交付文件仍可访问。清理失败可进行不影响其他文件的重试；仍失败时简要指出残留位置，不声称已经清理。

禁止删除或改写：用户输入、运行前已存在的文件、历史任务产物、技能自带脚本、模板、`.result` 源文件、共享环境依赖及其他任务缓存。不得清空整个工作区、系统临时目录、`.tmp/` 或 `outputs/` 来实现清理。

只有最终交付文件出现在给用户的文件链接中。参数检查与处理摘要使用对话说明，不另存报告。用户主动要求保留调试资料时，才按其要求保留对应文件。
