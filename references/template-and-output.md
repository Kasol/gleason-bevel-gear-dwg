# 模板约定、占位符、输出话术

---

## 1. 模板目录

```
gleason-bevel-gear-dwg/
├── SKILL.md
├── .template/
│   ├── bevel-gear-finished.dwg      # 首选
│   └── bevel-gear-finished.dxf      # 次选（DWG 转换产物）
└── references/ scripts/
```

装载顺序：`.dwg` 优先；只有 `.dxf` 时用 `.dxf`，并在输出里注明"基于 DXF 模板生成，DWG 由转换得到"。

目录规则：

- 目录名固定为 `.template`（带前导点），与 `SKILL.md` 同级
- 目录内允许有多个模板时，按文件名前缀匹配零件类型；匹配不上就停下来问，不要挑一个最像的
- 模板缺失 → 停止，话术见 `SKILL.md` 第 4 步

## 2. 占位符命名

模板中的待填文字统一写成 `{{KEY}}`，全大写、下划线分词、不带空格。

| 占位符 | 对应字段 |
|---|---|

### 2.4 标题栏（视模板实际布局取舍）

`{{PART_NO}}` 图号、`{{PART_NAME}}` 名称、`{{MATERIAL}}` 材料、`{{DRAWN_BY}}` 设计、`{{DATE}}` 日期。

模板中没有对应位置的占位符，忽略即可，不要新开文字框硬塞。

## 3. 回填契约

1. **只改文字值**。TEXT / MTEXT 的内容、图块属性的值，可以改。
2. **不改**图层、颜色、线型、字高、对齐方式、实体句柄、块定义结构。
3. **不动** [S]/[F] 标记的形状与位置（它们是独立实体或符号块，不是文字内容的一部分）。
4. **不动**图框、视图、标注、比例、图纸空间布局。
5. 一个占位符在模板里出现多次时（如模数在参数表和标题栏各一处），**全部替换**，保持数值一致。
6. 回填后复查：全图不应再残留 `{{` 字符。残留即视为失败，先修再交付。

`scripts/fill_dwg.py` 实现了 1、5、6 三条，并给了 `--dry-run` 先查漏。

### 4.2 风险备注必须写满的几类

- 几何参数来源与分支（A/B/C，以及 MCP 是否可用）
- 分支 C 中手填值与 MCP 提取值的差异明细
- 已按假设填写的项（如"侧隙测量位置按大端法向假设""轴交角按默认 90°"）
- 表 2 建议补录项的缺失情况
- 齿高类型与用户声明齿制不一致的情况
- 准双曲面（偏置距 ≠ 0）的拦截或人工确认记录

### 4.3 免责提示（逐字，不改写）

```
提示：本图纸由参数自动套用模板生成，S 为关键特性、F 为重要特性；正式投产前请人工复核锥齿几何、啮合参数、热处理及公差要求。
```

### 4.4 语言

- 输出语言**跟随用户提问语言**：中文问中文答，英文问英文答
- 但以下内容**始终使用中文原文，不翻译**：技术要求 5 条、[S]/[F] 标记、免责提示
- 英文输出时参数名与单位可用英文（如 `Module: 5.0 mm`），条款原文仍原样引用中文
- 英文输出时中文参数名保留括号对照，如 `大端端面模数（transverse module at outer end）`
