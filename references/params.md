# 参数与校验边界

本文件用于二维成品图 Tool 的参数检查和信息核对。以下保留现有锥齿轮字段作为首期基线，不是所有齿轮或机械零件的统一必填清单。真实生成的必填字段由零件类型、模板与业务规则确定，规则配置与结构化业务接口尚未实现。

两条路径均可使用下述检查。默认流程记录失败、差异或无法判断的项目后继续交付，不等待冲突确认；只有 [执行约定](execution.md) 中明确缺少的必要输入才追问。真实生成按适用规则处理工程冲突。

## 1 齿形字段基线

| 字段 | 符号／现有占位符 | 注意事项 |
|---|---|---|
| 齿制 | GEAR_TYPE | 格里森是加工体系，等高齿是齿高形式，不能混作单一分类维度 |
| 齿高类型 | GEAR_HEIGHT_TYPE | 收缩齿／等高齿等，保留声明及判别依据 |
| 大端端面模数 | mt／MT | 区分端面、法向及对应位置 |
| 齿数 | z1／Z1 | 当前件 |
| 齿形角 | α／ALPHA | 压力角及其口径 |
| 节圆直径 | d／PITCH_D | 明确对应位置 |
| 轴交角 | Σ／SHAFT_ANGLE | 缺失时不自动补 90° |
| 中点螺旋角 | βm／SPIRAL_ANGLE | 保留角度格式及测量位置 |
| 螺旋方向 | SPIRAL_HAND | 当前件的左旋／右旋 |
| 精度等级 | ACCURACY | 保留标准号及版本，特性标记独立表达 |
| 配对齿轮图号、齿数 | MATE_DWG_NO、MATE_Z | 与当前件区分；身份脱敏时按规则处理图号 |
| 全齿高、齿顶高、齿根高 | h、ha、hf／TOTAL_HEIGHT、ADDENDUM、DEDENDUM | 统一单位与定义 |
| 顶锥角、节锥角、根锥角 | δa、δ、δf／FACE_CONE_ANGLE、PITCH_CONE_ANGLE、ROOT_CONE_ANGLE | 保留角度口径 |
| 偏置距 | E／OFFSET | 非零时不能套用普通相交轴锥齿轮公式 |
| 侧隙 | j／BACKLASH | 可为单值或范围，保留测量位置；null 是缺失，不能默认为零 |

业务示例还包含齿圈跳动公差 Fr、齿距极限偏差 fpt、齿距累积误差 FPT，需按模板和规则保留，不能因为旧占位符清单没有就丢弃。

真实生成时，齿宽、齿顶间隙、变位系数、齿根圆角半径、材料等是否必填取决于模板及校验规则；默认流程不因此新增补充门槛。扩展其他零件类型时使用对应字段和规则，不强套锥齿轮表。

## 2 几何参数与尺寸表达

首期业务给出的四项基本几何参数：内孔直径、最大外径、安装距、模数。它们并不保证足够驱动任意零件轮廓；真实生成还需要的结构尺寸由模板映射列出，缺失时补充。

尺寸需要保留：名义值、单位、上下偏差或公差表达、直径／半径等符号、基准／测量口径、特性标记及原始表达。不得将 `φ130` 的偏差和 `[F]` 丢掉后仅保存数值 130。

例如业务示例可理解为以下信息；这不是现有脚本的 JSON 协议：

| 尺寸 | 名义值 mm | 下偏差 mm | 上偏差 mm | 标记 |
|---|---|---|---|---|
| 内孔直径 | 130 | +0.043 | +0.068 | F |
| 最大外径 | 304 | -0.5 | 0 | — |
| 安装距 | 102 | -0.027 | +0.027 | F |

模数必须标注定义及位置，与齿形数据中的模数进行同口径比较。不能仅因图纸写了法向模数就无条件使用中点螺旋角换算大端端面模数；换算须有适用公式、位置和业务依据。安装距基准未知时保留原文并标记待确认，不能断言不同基准总相差某个固定尺寸。

## 3 数据来源及合并

先读取可识别的草图信息，再与显式参数合并并检查完整性。齿形参数仅在有可靠来源时使用；是否需要用户补充按执行约定处理，不把解析能力不足当作未提供资料。

每个字段保留原文、来源文件及可定位位置（如页码、实体或单元格）、直接输入／识别／换算来源，以及未确认状态。用户明确输入优先，保留识别差异，不自动改值。默认流程简要记录工程冲突后继续交付；只有真实生成需要等待冲突确认。

公差或特性标记差异也属于差异，不仅比较名义值。差异阈值应由字段和规则定义，不统一用 0.5 mm 或 1% 过滤精密尺寸问题。未可靠识别、空值及不确定的角度格式不能当作完整数据。

## 4 校验适用范围

规则用于发现矛盾，不能替代齿轮设计或强度校核。公式与数值容差应随业务规则维护，并用已校核样本确认，不把旧技能的经验区间当作通用标准。

| 检查 | 适用条件与处理 |
|---|---|
| d = mt × z1 | d 与 mt 均指同一大端端面口径时检查 |
| tan δ1 = z1 / z2 | 仅用于轴交角 90°、无偏置的普通锥齿轮 |
| Σ = δ1 + δ2 | 只在适用的相交轴锥齿轮定义下，且两轮节锥角均有依据时检查；不反推缺失值后宣称独立验证 |
| h = ha + hf | 三者定义和位置一致时检查 |
| 齿高类型及锥角关系 | 根据齿制及模板规则判断，不能单凭“格里森”断定齿高类型 |
| 侧隙、精度及公差 | 根据模数、位置和适用标准／客户要求校验，不能用固定侧隙范围覆盖所有齿轮 |
| 参数与模板范围 | 校验所需结构尺寸、可变范围及形状适配，不能仅填文字而跳过几何一致性 |

E ≠ 0 时普通相交轴公式不可用；若无适用的准双曲面规则及已校核数据，记录无法校验，默认流程继续交付。真实生成则暂停并说明缺口。其他规则未覆盖的情况同样不能写成校验通过。
