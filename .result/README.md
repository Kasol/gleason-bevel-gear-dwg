# 业务结果文件

本目录保存默认交互流程使用的既有结果，交付时直接引用，不覆盖、改名或按当前参数重写。

| 结果 | 文件 |
|---|---|
| 二维成品图，有草图和无草图场景共用 | `finished-drawings/result.pdf` |
| 控制计划表 | `control-plans/result.xlsx` |

装配展示、干涉高亮和非标件图纸结果尚未提供，不能使用上述 PDF 替代。后续补充结果时同步维护 [执行约定](../references/execution.md) 的映射。

只有提示词明确要求调用真实服务时才走完整工具链；真实服务失败不得用本目录结果替代。本目录文件的存在不代表已经按当前输入重新生成或验证脱敏。
