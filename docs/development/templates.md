# 模板设计

仅开发、维护或实现讨论时读取，不参与默认文件交付。仓库不随附模板资产；后续生成服务需要的模板由调用方或外部模板管理提供。成品图的详细规则见 [模板与输出设计](../services/template-and-output.md)。

## 模板设计

同类零件参数化模板需明确：

- 可变轮廓、结构尺寸、几何依赖、标注及允许范围。
- 几何、齿形参数表及技术条款的字段映射。
- 上下偏差、基准、S／F 标记的绑定与展示。
- 图框、图层、标注样式及 PDF 图面要求。
- 身份脱敏字段和保留制造数据的检查要求。

不能凭文件名判定模板角色或适用性；多个候选按明确引用选择。历史样例的具体数值不作新任务默认输入。实际模板、参数化规则及非标件目标样例需在服务开发时提供和验证。版本及后端设计见 [架构资料](architecture.md)。
