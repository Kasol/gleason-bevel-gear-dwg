# 模板与输出约定

本文件是 [服务开发资料](README.md)，仅在明确开发、维护或讨论实现时读取，不属于默认业务执行步骤。描述的 CAD 生成后端尚未实现，DXF 回填只是现有辅助脚本。普通交付只按 [交付规则](../../references/execution.md)，不运行本文件的生成步骤。

## 1 模板及参数化规则

成品图基于公司提供的 DWG 模板，对同类零件进行参数化修改。模板需配套明确可变几何、尺寸依赖、参数表和技术要求的映射；只有 `{{KEY}}` 文字占位符不足以支撑几何变化。

`.template/` 是本地模板位置约定；服务通过模板引用和版本选择模板，优先采用明确指定且匹配零件类型的模板。多个候选无法确定时请求选择，模板或参数化规则缺失时暂停服务生成。

目前有 `.template/finished-drawings/empty.dwg` 和 `typical.dwg`，实体及参数化适用性待验证。调用生成服务需明确模板及其可变规则。

图框、标题栏样式、图层规范、标注样式及特性展示样式遵循模板。允许按规则改变零件轮廓、尺寸与标注、相关视图和标记位置；变化不得破坏特性对应关系。超出已验证的结构变化范围时返回不支持或待补充规则，不能只改尺寸文字掩盖几何不一致。

DXF 可以作为转换后的内部格式或回填测试输入，但不能把 DXF 输出当作已完成约定的 DWG 参数化处理与脱敏 PDF 交付。转换及 PDF 导出后端尚未实现。

## 2 现有文字回填接口

`scripts/fill_dwg.py` 接受 DXF 模板和一个字符串字典，替换布局 TEXT／MTEXT 及 INSERT 属性中的 `{{KEY}}`。它只负责文字，不修改几何或尺寸标注，不解析完整业务参数，不实现导出和脱敏。

以下是旧模板可复用的字段名，不是所有零件的完整字段 schema。扩展字段必须由模板映射及调用方同时提供，不能因此丢掉输入中的公差和其他制造要求。

| 分类 | 已约定 key |
|---|---|
| 齿制及类型 | GEAR_TYPE、GEAR_HEIGHT_TYPE |
| 基本齿形 | MT、Z1、ALPHA、PITCH_D、SHAFT_ANGLE、SPIRAL_ANGLE、SPIRAL_HAND、ACCURACY |
| 配对齿轮 | MATE_DWG_NO、MATE_Z |
| 齿高 | TOTAL_HEIGHT、ADDENDUM、DEDENDUM |
| 锥角与其他 | FACE_CONE_ANGLE、PITCH_CONE_ANGLE、ROOT_CONE_ANGLE、OFFSET、BACKLASH |
| 基本几何 | BORE_D、OD_MAX、MOUNT_DIST、MODULE |
| 技术要求 | CASE_DEPTH、SURFACE_HRC、CORE_HRC、CHAMFER、FILLET_R、TOL_CLASS |
| 标题栏 | PART_NO、PART_NAME、MATERIAL、DRAWN_BY、DATE |

典型调用：

```powershell
python scripts/fill_dwg.py --template 模板.dxf --values values.json --dry-run
python scripts/fill_dwg.py --template 模板.dxf --values values.json --write --out 回填结果.dxf
```

- `values.json` 的 key 不带花括号，值是已格式化文字。结构化尺寸应在业务层保留完整信息，再通过模板映射生成这些文字。
- dry-run 只检查扫描范围内所需 key 是否有值，不证明几何校验、参数化规则或所有技术字段完整。默认不写文件。
- 写入前先 dry-run；缺 key 时脚本拒绝写入。同一占位符多次出现会全部替换，写入后重读复查。
- 块定义内部文字及表格实体单元格不在扫描与替换范围内。扫描返回成功不等于全图无残留，正式出图需另做完整内容和图面检查。
- 只允许把它作为文字回填阶段的辅助工具，不以它替代 CAD 后端。

## 3 成品 PDF 与脱敏

服务主要交付物是整合几何、齿形和技术要求的成品 PDF。内部 CAD 中间文件可在处理中临时保存，结束后按 [任务文件管理](../../references/task-files.md) 清理，不作为额外交付物。

脱敏范围为公司、客户、人员及指定身份标识。具体清单待业务提供；图号等字段是否需要替换依据清单确定，不盲目清空所有标识。保留尺寸、公差、材料、热处理等制造要求以及 S／F 标记，供控制计划生成。

脱敏需要真正移除身份信息，不能只盖一块白色矩形。检查范围包括可见图面、可提取文字、元数据、文件名及可交付摘要；原始文件与未脱敏 CAD 不能混入对外交付引用。具体实现随 PDF 后端选择，当前脚本没有脱敏能力。

## 4 结果说明

服务生成的文件附参数与来源摘要、校验情况、脱敏说明和未决项，只对实际完成且检查通过的阶段报告成功。现有辅助脚本的“复查通过”只代表自身扫描范围。

如仅有 DXF 文字回填结果，应明确称为辅助产物，说明参数化几何、PDF 导出或脱敏是否未完成，不输出固定的“成品已生成”话术。

成品图应提示使用前人工复核几何、啮合参数、热处理及公差；非标件出图应明确为视图和基础尺寸草稿。说明语言跟随用户，技术原文保留确认内容，不再强制统一的成功话术或免责声明逐字模板。
