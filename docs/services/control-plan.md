# 控制计划真实生成设计

本文件从运行时检查说明拆出，仅用于后端开发、维护或实现讨论。当前未提供完整控制计划生成后端，不是普通“生成控制计划”的执行步骤；默认交付见 [交付规则](../../references/execution.md)。

## 输入与依据

- 成品 PDF：保留制造尺寸、公差、材料、技术要求及特性标记。
- 工艺路线／过程图 Excel：确定工序编号、顺序及特性。
- 控制计划模板：确定列、格式及填写要求。
- 适用历史案例和业务规则：为方法、设备、频次、抽样及反应计划提供可追溯依据。

模板、历史案例不是默认交付要求用户补交的资料。历史案例必须确认适用性，不能静默覆盖当前图纸或工艺路线。

## 后端实现步骤

1. 解析图纸与流程，保留尺寸、公差、标准、S／F 标记及来源。
2. 对应工序与产品／过程特性；无法可靠关联的项目保留待确认，不任意分配。
3. 结合规则及适用案例填充控制内容，记录依据。无依据频次、设备或反应计划不能写成已核实标准；建议与已确认要求分开。
4. 按模板生成 Excel，检查工序覆盖、必填列、单位、标记、公式及布局。不以脚本能保存文件代表内容通过工程验证。

## 输出边界

交付实际后端生成的控制计划，来源与未决项摘要留在对话，不自动新增独立报告。脱敏覆盖表头、人员字段、文件名及元数据，保留制造数据；仅对实际完成的阶段报告成功。输入 PDF 可独立提供，不依赖成品图业务的私有中间文件。
