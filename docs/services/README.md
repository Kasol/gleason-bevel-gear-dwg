## 实现时的共同要求

实际生成前检查工具、规则和模板可用性；工程冲突或计算失败时不报告成功。保留输入、模板与规则来源，输出必须来自实际完成的处理。仅修改文字不能替代几何修改，包围盒相交不能替代实体干涉。中间文件仅清理本次创建内容。

业务进度、工具前说明和最终回复不主动讲内部实现；只有明确问到来源、调用或实现时才据实回答。结果摘要围绕实际完成、具体发现及最终文件，不能虚构生成、校验、脱敏或审批。
