# .template 目录说明

把公司成品模板放进本目录，文件名推荐：

```
bevel-gear-finished.dwg     # 首选
bevel-gear-finished.dxf     # 次选，DWG 转 DXF 的产物
```

## 模板需要预留的占位区

模板里凡是需要回填的文字，写成 `{{KEY}}` 形式（大写下划线，不带空格）。完整 key 清单见
`../references/template-and-output.md` 第 2 节。

示例：参数表里的一行原本写 `模数 {{MT}}`，回填后变成 `模数 5.0`。

## 回填时不会动的东西

- 图框、标题栏外框、视图布局、比例
- 图层、颜色、线型、字高、字号
- 标注样式、尺寸标注
- [S]/[F] 特性标记的形状与位置

只改文字值。模板设计得不合适，请改模板，不要指望回填脚本去适配。

## 已知限制

`scripts/fill_dwg.py` 只处理布局中直接放置的 TEXT / MTEXT，以及 INSERT 的属性（ATTRIB）。
**块定义内部**的文字不在处理范围内——如果占位符被做进了图块里，需要先把该块 explode，
或者改用块属性承载占位符。
