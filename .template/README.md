# 模板资料位置

本目录存放模板资料，`.result/` 存放交付文件。文件交付按 [交付规则](../references/execution.md) 完成；调用生成服务时再验证模板及参数化规则。

## 已提供资料

- `finished-drawings/empty.dwg`
- `finished-drawings/typical.dwg`
- `control-plans/typical.xlsx`：含 14 道工序的大锥齿轮控制计划样例，既有具体数据不能作为所有新零件的默认值。

两个 DWG 的内部实体、模板角色及参数化适用性尚待确认，不能仅按文件名断定各自可用于哪种生成步骤。

## 成品图模板

公司 DWG 模板用于同类零件参数化出图，需要同时明确：

- 可变的轮廓和结构尺寸、几何依赖、尺寸标注及允许变化范围。
- 几何参数、齿形参数表及技术要求的字段映射。
- 上下偏差、基准、S／F 特性标记的绑定与展示规则。
- 图框、图层、标注样式，以及 PDF 图面要求。
- 需要脱敏的身份字段；制造数据保持可用。

命名可使用 `bevel-gear-finished.dwg`，转换后的 DXF 仅作为内部处理文件。多个模板按明确引用及适用类型选择，不凭文件名猜测。

## 其他模板

控制计划已有上述 Excel 样例，配套历史适用条件和业务规则仍需确认。非标件二维工程图需要工程图模板，首期目标为视图与基础尺寸草稿，对应资料尚未提供；后续组织方式及服务中的模板版本管理见 [架构说明](../references/architecture.md)。

## 现有回填脚本的限制

仅做文字回填测试时，可在 DXF 的 TEXT／MTEXT 或块属性中放置 `{{KEY}}`，例如 `模数 {{MT}}`。字段见 [模板与输出约定](../references/template-and-output.md)。

`scripts/fill_dwg.py` 只替换这些文字，不修改几何、尺寸标注、图层或布局；它不支持块定义内部文字及表格单元格，且残留检查也看不到这些内容。优先在测试模板中使用可处理的文字或块属性，不自动炸开或破坏业务模板。

“只改文字”是当前辅助脚本的能力边界，不是完整成品图 Tool 的业务限制。不得把该脚本的结果视作已经参数化修改、导出和脱敏的成品 PDF。
